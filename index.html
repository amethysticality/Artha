Welcome to Artha!

     Artha is a language learning tool designed to augment contextual understanding of linguistic phrases and vocabulary through culture and music. Each language (French is the default for beta testing but more will be added as additional functionalities are added).
For information on how to use the tool, consult the section that follows this one.

How to Use Artha

     Artha is best used concurrently with more formal modes of language learning, such as in-school courses. To navigate to a language tab in beta, use the hamburger icon in the top-right corner, and using the menu, navigate to your preferred language. Then use the notes and vocab as study guides for culturally relevant phrases, preferably on a physical medium, like flashcards.
